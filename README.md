# SATTO KAKU

A simple, lightweight writing editor by **HAL WORKS**.
▶ [Open SATTO KAKU](https://peacemaker1984.github.io/satto-kaku/)

「さっと書く」は、思いついた文章をすぐに書き始めるための、シンプルで軽量なWebテキストエディタです。

ブログの下書き、レポート、歌詞、アイデアのメモなど、「とにかく今すぐ書きたい」というときに使えることを目指しています。

## Features

- ブラウザですぐに使える
- 入力内容をブラウザに自動保存
- リアルタイム文字数・行数表示
- クリックで400字詰め原稿用紙の枚数に換算
- 直前の内容をバックアップして復元
- テキストファイルを開く・保存
- 全文をワンクリックでコピー
- PC・スマートフォンなど複数のデバイスから利用可能
- インストール不要

## About auto-save

入力した内容は、その端末のブラウザ内に自動保存されます。
サーバーには保存されません。

そのため、別の端末や別のブラウザには文章は自動的に同期されません。
大切な文章は「保存」ボタンでファイルとして保存することをおすすめします。
